# vzrecon

Protocol-level proxy validator for HTTP, SOCKS4, and SOCKS5.
Developed by VZLOI GROUP.

## Features
- HTTP CONNECT (RFC 7231)
- SOCKS5 (RFC 1928)
- SOCKS4
- --verify mode
- Zero dependencies
- Termux-native
- asyncio based

## Install
pip install vzrecon
